# OsaiTransfer — Автономный менеджер программ ЧПУ «Нестинг» (OSAI COMPACT)

Портативное Windows-приложение с графическим интерфейсом для двусторонней передачи управляющих программ (`.anc`, `.cnc`, `.pgm`, `.txt`, `.nc`), макросов и файлов между ПК оператора (Windows 11) и контроллером ЧПУ OSAI COMPACT (Windows CE).

Подробная хронология диагностики и всех изменений — в [CHANGELOG.md](CHANGELOG.md).

---

## 🎯 Назначение и решение проблемы Win32 58

После обновления Windows 11 до 24H2/25H2 системный Проводник и сторонние Win32-менеджеры блокируют перечисление сетевых папок стойки ЧПУ (`\\192.168.0.2\USER` и `\\192.168.0.2\OEM`) с ошибкой **Win32 58 (`ERROR_BAD_NET_RESP`)** в драйвере ядра `mrxsmb10.sys`.

**Как решена проблема:**
1. **Чистый Userspace SMB 1.0:** сетевой обмен работает напрямую через TCP-сокет (порт `445`) поверх библиотеки `pysmb`, без вызовов Win32 API ядра Windows к сетевым путям контроллера.
2. **Особенности Windows CE (OSAI COMPACT):**
   - парсер отсекает завершающий NUL (`rstrip('\x00')`) в полях имён `TRANS2_FIND_FIRST2`;
   - поддержаны **обе кодировки имён**, встречающиеся на контроллере: нативный UTF-16LE (например, `/PROGRAMS/В РАБОТУ`) и устаревшие имена CP1251-в-Latin-1 (например, `/PROGRAMS/WORK/338 фанера 20`), с посегментным разрешением путей `resolve_remote_path()`;
   - прямое удаление файлов и папок (`ComDeleteRequest`, `ComCreateDirectoryRequest`, `ComDeleteDirectoryRequest`) с обязательным ведущим слэшем `\`;
   - автоматический сброс сессии при усечённых пакетах ошибок WinCE (`ProtocolError`) с расшифровкой NTSTATUS.
3. **Защита станка:** приложение работает только с файловой системой контроллера — без управляющих команд станка и вмешательства в переменные ЧПУ.

## 🖥 Возможности интерфейса

- **Двухпанельный интерфейс (ПК оператора ↔ Стойка ЧПУ OSAI COMPACT):**
  - **Левая панель (ПК):** выбор каталога, разрешение Windows-ярлыков (`.lnk`, включая сетевые папки), фильтр УП (`*.anc;*.cnc;*.pgm;*.txt;*.nc`) или `Все файлы (*.*)`.
  - **Правая панель (ЧПУ):** переключение ресурсов `USER` / `OEM`, навигация, создание и рекурсивное удаление папок (с защитой системных каталогов).
- **Сортировка по столбцам:** клик по заголовкам `Имя файла / папки`, `Размер`, `Дата изменения` в обеих панелях (`▲`/`▼`, `..` закреплена сверху, папки перед файлами).
- **Drag & Drop:**
  - перетаскивание файлов и папок мышью между левой и правой панелями внутри приложения (загрузка на ЧПУ и скачивание на ПК);
  - перетаскивание файлов из Проводника Windows прямо в окно программы (`tkinterdnd2`).
- **Просмотр файлов и контекстное меню (ПКМ):**
  - **На левой панели:** нативное системное контекстное меню Windows (`IContextMenu`: *Открыть*, *Открыть с помощью*, *Свойства* и др.) + `Загрузить на ЧПУ ➔` и `Быстрый просмотр текста`.
  - **На правой панели (ЧПУ):** `👁 Открыть в программе Windows` (через временный кэш `%TEMP%\OsaiTransferPreview` поверх Userspace SMB1 — для `.bmp`, `.pdf`, УП), `📄 Быстрый просмотр текста (УП)` (UTF-8 / CP1251) и `🪟 Системное меню Windows...`.
- **Индикация связи и горячие клавиши:** фоновая проверка порта `445` каждые 5 секунд (`🟢` / `🔴`), `F5` (обновить всё), `Delete` (удалить выбранное на ЧПУ), двойной клик (переход по папкам).

## ⚙ Конфигурация (`config.ini`)

Рядом с `OsaiTransfer.exe` располагается `config.ini`:
```ini
[CNC]
host = 192.168.0.2
port = 445
remote_name = COMPACT
client_name = OPERATOR-PC
share = USER
remote_dir = /PROGRAMS/WORK
timeout = 5
username = 
password = 123

[Local]
default_path = C:\Users\OEM\Desktop
extensions = *.anc;*.cnc;*.pgm;*.txt;*.nc

[App]
theme = light
ping_interval = 5
```

## 📦 Сборка в один файл `.exe` (Portable)

Зависимости указаны в [requirements.txt](requirements.txt): `pysmb`, `pyinstaller`, `pywin32`, `tkinterdnd2`.

- **Локальная сборка:** запустите [build.bat](build.bat) (создаст `venv`, установит зависимости и соберёт `dist\OsaiTransfer.exe`).
- **Удалённая сборка на целевом ПК:** используйте [build_remote.cmd](build_remote.cmd) (сохраняет существующий `config.ini` на Рабочем столе оператора).
